# Olist Supply Chain Portfolio

Three end-to-end supply-chain case studies on the [Olist Brazilian e-commerce dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (~100k orders, 2016–2018). They are built with **Python + SQL** and presented in two ways:

- **Portfolio website (main): hosted on Vercel** (`*.vercel.app`, link added after the first deploy). Static, fast and always online.
- **Interactive lab: [site-selection-vrp.streamlit.app](https://site-selection-vrp.streamlit.app/)**. A Streamlit app for exploring the data.

| # | Project | Status | Folder |
|---|---|---|---|
| 0 | Data foundation: cleaning pipeline, cleaning log, validations | ✅ Done | [data_pipeline/](data_pipeline/README.md) |
| 1 | Site selection: how many fulfilment centres, and where? | ✅ Done | [site_selection/](site_selection/README.md) |
| 2 | Vehicle routing: daily last-mile routes from the São Paulo FC | ✅ Done | [vrp/](vrp/README.md) |
| 3 | Inventory: what the São Paulo FC stocks, reorder points, simulation | ✅ Done | [inventory/](inventory/README.md) |

## Repository layout

```
├── docs/                     # static portfolio website (Vercel), generated by docs/build.py
├── vercel.json               # Vercel config: serve docs/ as a static site, no build step
├── streamlit_app.py          # Streamlit app entry point (navigation)
├── app_pages/                # one file per app page
├── app_common.py             # shared app helpers (palette, loaders)
├── requirements.txt          # app dependencies (Streamlit Cloud)
├── data_pipeline/            # raw CSV -> clean SQLite tables + cleaning log
├── site_selection/           # SQL demand model, p-median optimisation, figures, outputs
├── vrp/                      # last-mile routing from the São Paulo FC (OR-Tools)
├── inventory/                # what the São Paulo FC stocks: segmentation, forecasts, reorder policy
└── archive/                  # raw Kaggle CSVs (not committed, download below)
```

The app only reads the small result files in `site_selection/outputs/` and `data_pipeline/reports/`, so it runs without the raw data or the database.

## Run locally

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt -r site_selection/requirements.txt   # macOS/Linux: .venv/bin/pip
.venv/Scripts/streamlit run streamlit_app.py
```

To rebuild every result from scratch, download the dataset from Kaggle, unzip it into `archive/`, and run:

```bash
.venv/Scripts/python site_selection/run_all.py
```

## Portfolio website (Vercel)

The site in `docs/` is generated from the project outputs, so the numbers always match the analysis:

```bash
.venv/Scripts/pip install markdown
.venv/Scripts/python docs/build.py      # rebuild after changing any result
```

**Hosting on Vercel (free):**

1. Sign in at [vercel.com](https://vercel.com) with GitHub.
2. **Add New → Project**, then import this repository.
3. Keep the defaults: `vercel.json` already sets *Framework: Other*, no install or build command, and output folder `docs`.
4. Click **Deploy**. Every push to `main` redeploys automatically.

After changing any result, run `docs/build.py` and push.

## Deploy to `*.streamlit.app` (free)

1. Push this folder to a **public GitHub repository**.
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub, and click **Create app**.
3. Pick the repository and branch, and set **Main file path** to `streamlit_app.py`.
4. Under **Advanced settings**, choose Python **3.12** or newer. Pick a custom subdomain (e.g. `olist-supply-chain`) and click **Deploy**.
